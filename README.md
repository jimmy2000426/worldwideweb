# Style & Trim

理髮預約系統的 React 前端與後端規格文件。

## 開發前端

```bash
cmd /c npm install
cmd /c npm run dev
```

## 專案內容

- `src/`：React 前端
- `agent.md`：給後續 agent 的工作守則
- `content-architecture.md`：各頁內容架構
- `ui-ux-direction.md`：UI/UX 設計方向
- `frontend-spec.md`：顧客前台內容與視覺規格
- `backend-spec.md`：FastAPI / PostgreSQL 後端規格

## 路由

- `/`：首頁
- `/login`：登入 / 註冊
- `/booking`：預約頁
- `/appointments`：我的預約
- `/dashboard`：員工後台
